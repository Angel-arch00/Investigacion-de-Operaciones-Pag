FÓRMULAS APLICADAS

1. Lote Óptimo de Pedido (EOQ):
EOQ = √ ( 2·D·S / H )
EOQ = √ ( 2 · 1000 · 50 / 5 ) = 141.42 u
2. Número de Pedidos / Año (N):
N = D / EOQ
N = 1000 / 141.42 = 7.07 pedidos
3. Tiempo entre Pedidos (T):
T = 365 / N
T = 365 / 7.07 = 51.61 días
4. Costo Total Anual (TC):
TC = (D/EOQ)·S + (EOQ/2)·H
TC = 707.11 + 353.55 = $707.11
5. Punto de Reorden (ROP):
ROP = (D / 365) · L
ROP = (1000 / 365) · 7 = 19.18 u
